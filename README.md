# LZYYMQ · 羽境 FEATHER COURT 7.21

7.21：对手会记住反复攻击的落点、偏移防守重心，并在被拉吊或突然变线后出现被动回球。增加实际得分归因、三项局内挑战和暂停战术报告。中键切换直线 / 斜线；左键智能找空当、右键仍然杀球。保留八款球拍与立体球馆窗景。

离线第一人称 3D 羽毛球游戏，页面品牌名为 LZYYMQ。Three.js 与场景资源随包提供，不依赖 CDN。

## 快捷球路

- `1` 智能回球
- `2` 高远球
- `3` 吊球
- `4` 杀球
- `5` 网前搓球
- `6` 推后场
- `7` 勾对角
- `8` 劈杀斜线
- `9` 劈吊对角

鼠标左键始终智能接球，右键始终杀球；空格跳跃，WASD 移动。暂停后鼠标归还页面。首页点击林丹、李宗伟、谌龙或陶菲克模式即可直接套用对应的玩家属性。

鼠标中键依次切换球路默认、直线、斜线；滚轮选择前后场，Z / C 微调左右，X 恢复球路默认。手动落点优先，起拍后落点锁定。Tab 查看对手战术观察，Esc 查看本场各球路制胜分及挑战进度。活动回合保留简洁比分，死球后短暂显示得分原因。

对手的分级和球星预设是游戏参数参考。弱点、适应与回球质量通过真实位置、运动方向和接球高度计算，不保证某种按键或战术必定得分。自动与手动移动使用相同体力规则；充分到位的对手能恢复正常回球质量。

## 本地运行

```powershell
npm install
npm run build
$env:PORT=5180; node dist/server.mjs
```

默认只监听本机。若要让同一局域网访问，可在明确需要时运行 `$env:HOST='0.0.0.0'; $env:PORT=5180; node dist/server.mjs`，再用主机局域网地址访问。公开版已部署到 GitHub Pages，链接见下文。

## 鹰眼与落地动画

死球后按 **B**，或暂停后点击“查看上一拍鹰眼回放”。边线附近自动慢放，可暂停、拖动、重播和选择 0.2× / 0.35× / 1×；暂停面板可关闭自动鹰眼。只按球头首次触地范围判线，压线算界内，回弹不影响已经判定的比分。触地后有低幅回弹、二次轻跳、摩擦滑动和羽毛侧倒。

公开试玩：https://lzyedward.github.io/lzyymq/

## 6.5 技术更新

首页和暂停中的“双方实力调节”提供双方各六根独立拉杆。8 劈杀斜线、9 劈吊对角，小键盘同样支持；7 勾对角默认勾到触球位置的对面前角，X 取消手动落点并恢复球路默认。H 显示额外操作按钮。左右键不变。重杀与轻球采用不同幅度的落地反弹和擦地运动。

## 7.12 画面、动作与省电

本轮包含完整肩肘腕五指蒙皮、解剖皮肤、藏青球拍连续涂装与实体交织拍线、PVC 微表面与垂度球网。肩部有界前伸减轻高位拉长；左手由发球收回到平衡准备。模型是通用解剖网格，极端超臂展辅助接球仍可能出现夸张伸展。

默认自动画质限制像素和 60 FPS，低负载模式进一步减少像素。菜单 15 FPS，暂停停止重绘，后台停止渲染。加载超时会降级，可用 `?safe=1` 启动轻量版本。未修改系统驱动。
