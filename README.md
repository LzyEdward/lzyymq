## 7.41 · 比赛原速与球星挑战

标准比赛双方按 100% 球速飞行。青色半环是脚下的接球站位，浅黄色地面投影跟着空中的球移动。首页可从 19 位知名男单球星中随机匹配，也可在 56 人全阵容里点名。选择「球星巅峰」按对手取等级，手选 1–10 级则按所选级别比赛。

高画质模式下，浏览器窗口大小改变后同步更新后处理缓冲，保持球场画面的正确宽高比。羽毛球按接近真实的尺寸随透视缩小，近球与远球有明确的比例差。两种视角均可显示球下方的地面投影与离地高度虚线，帮助判断球的前后位置和高度。朝预计接球位置移动会自动提速，按住 Shift 加方向键可主动冲刺，点 Ctrl 跨步救球。暂停可调整对方来球节奏及追球自动冲刺，两个视角共用设置。

防守需要站到球的飞行线路上，提前按键会保留击球意图。6 或小键盘 6 推后场，高点击球更平快，低点击球需要留过网高度。每位选手的球衣有背印，人物在跨步、侧移和挥拍时通过髋部、腰腹和肩膀传力。球衣设计参考了[林丹的比赛照片](https://commons.wikimedia.org/wiki/File:Lin_Dan_(CHN).jpg)和[李宗伟的伦敦奥运会照片](https://commons.wikimedia.org/wiki/File:Lee_Chong_Wei_in_the_2012_Summer_Olympics_(3to4_portrait).jpg)。

首页的八球专项包含接发球、网前手感、后场进攻和混合练习。对手自动从左右两边喂球。每球根据实际落点和球路判定，练完可查八球记录、再练一组或换项目。每项训练的最佳成绩保存在当前浏览器。

F2 切换视角，Y 归正镜头。第三人称默认近景，暂停后可切换全场。人物挡住近身来球时会淡化。两种视角的找球辅助用白色虚线标出球的离地高度，用青色半环标出接球时的站位。暂停可关闭找球辅助和击球时机提示。右键杀球时，默认根据触球位置选用中后场落点。要杀指定短点，可先选择杀球再手动定点。


暂停设置可分别开关自动回球、自动跑位和自动跟球视角；高球自动抬头默认开启，且与完整双轴自动跟球独立。设置会保存在本机。自动回球只在来球进入可击球窗口时出手，使用当前选中的击球方式；手动击球优先，自动回球不会替代跑位或视角控制。

鼠标左键始终智能接球，右键始终杀球；空格跳跃，WASD 移动。暂停后鼠标归还页面。首页点击林丹、李宗伟、谌龙或陶菲克模式即可直接套用对应的玩家属性。

鼠标中键依次切换球路默认、直线、斜线；滚轮选择前后场，Z / C 微调左右，X 恢复球路默认。手动落点优先，起拍后落点锁定。Tab 查看对手战术观察，Esc 查看本场各球路制胜分及挑战进度。活动回合保留简洁比分，死球后短暂显示得分原因。

对手的分级和球星预设是游戏参数参考。弱点、适应与回球质量通过真实位置、运动方向和接球高度计算，不保证某种按键或战术必定得分。自动与手动移动使用相同体力规则；充分到位的对手能恢复正常回球质量。

## 鹰眼与落地动画

死球后按 **B**，或暂停后点击“查看上一拍鹰眼回放”。边线附近自动慢放，可暂停、拖动、重播和选择 0.2× / 0.35× / 1×；暂停面板可关闭自动鹰眼。只按球头首次触地范围判线，压线算界内，回弹不影响已经判定的比分。触地后有低幅回弹、二次轻跳、摩擦滑动和羽毛侧倒。

## 7.12 画面、动作与省电

本轮包含完整肩肘腕五指蒙皮、解剖皮肤、藏青球拍连续涂装与实体交织拍线、PVC 微表面与垂度球网。肩部有界前伸减轻高位拉长；左手由发球收回到平衡准备。模型是通用解剖网格，极端超臂展辅助接球仍可能出现夸张伸展。

默认自动画质限制像素和 60 FPS，低负载模式进一步减少像素。菜单 15 FPS，暂停停止重绘，后台停止渲染。加载超时会降级，可用 `?safe=1` 启动轻量版本。未修改系统驱动。
